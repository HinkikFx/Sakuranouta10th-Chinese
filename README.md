# サクラノ詩 10th Anniversary Edition 简体中文翻译

《樱之诗 -在樱花之森上飞舞-》10周年纪念版 AI 简体中文翻译，仅供学习交流使用。

## 关于本翻译

本翻译使用Claude Fable5进行AI翻译，可能存在翻译不准确、语句不通顺等问题。如果你在游玩过程中发现明显的翻译错误，欢迎提交 Issue 或 Pull Request。
> 真的会有人用Fable5去翻译吗？
> 有的，兄弟有的，且在此之前是Opus4.6翻译的。

> 你这Fable5它保真吗？不能是什么低价中转站出来的吧？
> 那包保真的，在官方Claude Code中开WorkFlow跑翻译，模型选择Fable 5 High。

> 那么Fable5翻译质量能显著高于Opus/Gemini/GPT/...吗？
> Hummm... 其实我也不知道，但是很有趣不是吗o(*￣▽￣*)o

## 使用方法

将 `script` 文件夹放置到游戏目录下，覆盖原有文件即可。
